# Production Playbook — 端到端生产手册

`SKILL.md` 讲原则，本文件讲**手上的动作**。适用于从零建片，也适用于对已有成片做增量迭代。

---

## 1. 开工前：把方向写下来（guizang「先有方向，再写代码」）

在项目里写 `DIRECTION.md`，至少含：
1. 一句话主张 + 观众是谁 + 投放渠道 / 画幅；
2. **选定的视觉方向和理由**（从题材推导，不是从模板挑）；
3. 从题材推导出的 3–5 个专属手法，及各自对应题材的哪一点；
4. 画面规范：色板、字族、最低字高、安全区、双语制式；
5. 镜头表（key / 时长 / 内容 / 有无字幕 / 转场方式）；
6. 声音计划：BGM 来源与段落、每类事件音、是否配音（本类片子**默认无配音**）；
7. 硬约束：时长红线、风格基准、不可改动区段。

**没有方向文档不动代码**。用户给的脚本/参考图就是方向文档，先确认再实现。

---

## 2. 搭建顺序

`code-recipes.md` §1→§10：依赖/入口 → 色板 → timeline → Shell → 工具函数 → Grain → RollNum → CornerSub → 黑卡 → 合成根组件。
每完成一步跑一次 `npx tsc --noEmit -p .`。

**建片第一帧就要完整可读**（不是等待入场的空底）：先做开场镜的"完成态"，再往回加动画。

---

## 3. 迭代纪律（本片 v1→v34 的真实节奏）

| 阶段 | 动作 | 交付 |
|---|---|---|
| ① 改 | 只改被点名的镜头；`timeline.ts` 改 dur / 插 key → `scenes.tsx` 实现 → `OnePointFive.tsx` 注册 | — |
| ② 类型 | `npx tsc --noEmit -p .` | 必须通过 |
| ③ 算帧 | 手算绝对帧 `abs = 之前所有 dur 之和 + 局部帧`（别跑 `npx tsx -e`，沙箱会 SIGTERM） | 帧号表 |
| ④ 截图 | `scripts/qa_stills.sh` 批量出关键帧 + contact sheet | PNG |
| ⑤ 看图 | 用图像查看逐帧核验，可疑处 crop 放大 | 问题清单 |
| ⑥ 修 | 只修⑤发现的问题，回到④ | — |
| ⑦ 渲染 | 后台全片渲染（`--temp-dir` 必带），期间不并行跑重活 | mp4 |
| ⑧ 核验 | `ffprobe` 时长 + `ls -la` 大小 + 红线检查 | 版本号 vXX |
| ⑨ 交付 | 展示成片 + 一句话说明改了什么、其余未动 | — |

**版本号递增**（draft-v32 → v33），保留上一版便于回滚。每次只做一轮用户反馈，别顺手改别的。

## 4. QA 截图：怎么选帧（最容易出错的一步）

### 4.1 选帧策略
- **每个节拍后 +0.3s（≈9f）取一帧**，让入场动画落定；若那格还在动，说明 hold 太短。
- **打字机字幕要截"打完以后"的帧**：`at + 字数 × cps + 余量`（`cps=2.2` 时 20 字 ≈44f）。
- **状态变化取三帧**：变化前 / 变化中 / 变化后稳定帧。
- **转场取缝两侧**：上镜 `from + dur - 8`、下镜 `from + 8`、再加中间帧。
- **数字滚动**：滚动起点 + 滚动完成（`rollAt + 22`）。
- **多格快切**：每格至少一帧（格起始 + 格长/2）。
- **末卡**：完整显示帧 + 淡出中帧。

### 4.2 命令
```bash
# 批量（每行最多 6 帧，超过自动分行）
bash scripts/qa_stills.sh <projectDir> src/index.ts <CompositionId> out/qa-vXX \
  30 80 146 296 1245 1275 6700 6830 7281

# 局部放大查错位（左/上 crop 起点自己按画面调）
ffmpeg -y -loglevel error -i out/qa-vXX/f6830.png \
  -vf "crop=800:600:720:340,scale=1200:900" out/qa-vXX/zoom_water.png

# 手动拼图（6 帧一行，缩到 3840×540 便于看图）
ffmpeg -y -loglevel error -i a.png -i b.png -i c.png -i d.png -i e.png -i f.png \
  -filter_complex "[0][1][2][3][4][5]hstack=6,scale=3840x540" sheet.png
```

### 4.3 看图提问模板（给图像查看工具的自包含 prompt）
> 「这是 N 帧拼接，每帧 1920×1080 缩到 640×540。①… ②…（逐帧说明期望内容）。
> 请逐帧确认：文字是否清晰完整、位置是否居中、有无重叠/裁切/错位、金色标注是否醒目、元素是否接触/对齐。」
⚠️ 描述里必须写明**每帧是什么、期望看到什么**，否则容易得到泛泛回答。

### 4.4 本片真实抓到过的错位（说明为什么必须放大看）
| 问题 | 用户原话 | 修法 |
|---|---|---|
| 洒水壶嘴朝右，水滴落在 x≈1500，土堆右缘 1290 | 「水没有浇到叶子上」 | 壶嘴调转朝树 + 水滴 `cx=1028-i*9`，逐帧看是否落在叶面并顺干流到根 |
| 自行车轮底 y=674 而地面线 688 | 车轮悬空 14px | 轮子 cy 660→674 贴地 |
| 旗帜过大 | 「像门板」 | 缩到 55% 并移到两侧 |
| 融水画成独立白柱 | — | 改成贴着冰面的细融溪 |
| 光伏板浮在屋顶外 | — | 贴到屋顶斜面上 |
| 地图整张被删 | 「我最后只让你删了地图，没有让你把那个数据图删掉啊」 | 恢复地图框 + 经纬网格，只删大陆轮廓 |
| 知识卡贴边、排版紧 | 「稍微再大一点点，不用特别靠边」 | 放大卡片、留边距 |

## 5. 验收清单（review-loop + 审美准则，逐条打勾）

**没看过当前渲染的 contact sheet，不许报告完成。**

```
□ 一帧一个焦点，没有两个东西竞争
□ 无意外重叠/碰撞（尤其转场时出场与入场元素共存）
□ 重要内容距边缘 ≥60px；首帧是完整可读画面
□ 文字没被遮罩/容器/画面裁掉；缩到 360px 宽仍能读关键句
□ 字幕 ≥5% 帧高、辅助文字 ≥3% 帧高
□ 文字在被读时静止；落定后 hold ≥1s（结尾钩子 ≥2s）
□ 出场快于入场；场景重叠而非切到空帧
□ 只用 C 里的颜色；accent 只标出该帧重点
□ 同一元素在各镜长得一样
□ 全片一个 hero 时刻；glint/sheen ≤1–3 处且不群发
□ 一种动画手法只当一次主角（反单调）
□ 深色↔浅色之间没做长交叉淡化（会中间发灰）
□ 每个 cue 落在 spring 落定帧；两条偏移已补（见 assets-and-style B5）
□ 连续运动保持安静；−14 LUFS ±1 / TP ≤ −1 dBFS
□ 总时长在红线内；ffprobe 时长与文件体积正常
□ 审美准则 R1–R4 / Q4 / Q5 / Q11 / S1 / S3 / S4 / P1–P4 逐条标 ✓ 或 ✗(帧号)
```

**报告纪律**：说清检查了什么、改了什么、哪张 sheet 能证明；**没重新渲染并看过的修复不许声称完成**。

## 6. 用户反馈 → 动作映射（减少来回）

| 用户说法 | 正确动作 | 常见误解 |
|---|---|---|
| 「文字有点快 / 再慢一点点」 | 加长该镜 `dur` + 顺序拉开各段文字窗口 + **同步移动对位 SFX** | 只改最后一个镜头；或只调 fade |
| 「停留再久一点点」 | 延长该镜 dur，内部时序不动，让淡出自然后移 | 重排所有动画 |
| 「不是最后一段，从那个纬度之后」 | 先**完整 revert** 误改，再定位真正区段（s14/s14b/s14c） | 在错误版本上继续打补丁 |
| 「有的地方可以变成黑屏大字幕」 | 把该句**改成独立镜头**（黑卡），并从原角标里删掉，重排剩余字幕时间 | 在原有画面上叠大字 |
| 「重点标一下黄色」 | `CornerSub` 行的 `hi` 字段 / BlackCard `accent`，只标一个词或一段数字 | 整句标黄 |
| 「衔接根本没有」 | 上镜 `<Shell fadeOutFrames={26}>` + 下镜 `<Shell fadeIn fadeInFrames={22}>`，BGM 不断 | 加通用转场特效 |
| 「BGM 要贯穿全文」 | `<Sequence from={0}>` + volume 函数做 swell/淡出 | 只在某个镜头挂 BGM |
| 「只删地图 / 只改某处」 | 严格限定作用范围，删完恢复其余元素 | 顺手重构整段 |
| 「非必要不更改」 | 只动被点名段落，其余一帧不动 | 顺带优化 |
| 「尽快」 | 跳过全片渲染前的多轮打磨可商量，但**截图核验不能省** | 直接出视频 |

**模糊指代先确认对象**；改错就整体 revert。文案修正**逐字替换**，不润色、不合并、不省略。

## 7. 时长与红线

- `总帧 / 30 = 秒`；本片最终 7316f = **243.9s**，红线 4'30"（8100f）内。
- 每次加镜头/加长都要重算；**超红线立刻上报用户**，不擅自砍内容。
- 压缩时长优先级：缩短"字幕已走、画面干等"的空档 → 砍重复镜头 → 最后才压字幕停留（但别低于阅读速度）。

## 8. 渲染与排障

```bash
npx remotion render src/index.ts <CompositionId> out/draft-vXX.mp4 \
  --temp-dir=out/tmp-vXX --log=error          # 后台跑
```

| 症状 | 根因 / 解法 |
|---|---|
| still 全过、render 报音频 404 | still 不下载音频；检查所有 `<Audio>` 路径真实存在；无配音项目 `vo:false` |
| 渲染中途随机失败 | 默认临时目录音频竞争 → 独立 `--temp-dir` |
| `interpolate` 报 TypeError | 不能用它插 hex 颜色 → 双层同形 rect 交叉淡出 |
| 动画完成瞬间整组消失 | `if (draw<=0) return null` → 改单侧 `if (f<start) return null` |
| 滚动数字换行破基线 | inline-block 撑高 → 不可见占位 + 双绝对层 |
| 转场没生效 | timeline 的 fadeOut 只是元数据 → Shell 显式传 props |
| 渲染越来越慢 | 先算「时间÷帧数」归一化；实测音频非瓶颈、SVG 复杂度/机器负载才是；渲染时别并行跑 ffmpeg |
| `pip install` / `npx tsx -e` 被杀 | 沙箱 SIGTERM → ffmpeg+numpy 手写管线 / 手算帧号 |
| `git clone` GitHub 失败 | 代理只放行 `api.github.com` → codeload tarball 或 Contents API |

**性能纪律**：渲染前关掉 Studio/预览；后台渲染时不并行跑 ffmpeg/截图；
想提速先砍同屏 SVG 节点和给 Grain 隔帧/降分辨率（压缩音频收益实测很小）；
用 `--frames=x-y` 分段探针定位瓶颈（240 帧一组），别猜；默认并发通常已最优。

## 9. 交付

1. `ffprobe -v error -show_entries format=duration -of default=nw=1 out/draft-vXX.mp4`
2. `ls -la` 确认体积正常（≈4 分钟片 ~60MB）
3. 展示成片 + **一句话说明本版改了什么、其余未动**
4. 记录版本号到项目日志（本 workspace 用 `.workbuddy/memory/YYYY-MM-DD.md`）
5. 附上素材 `CREDITS.md` 与来源清单；没试听就如实说明
